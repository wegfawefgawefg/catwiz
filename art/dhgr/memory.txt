Catwiz double hi-res art: memory for the day fights (python3 tools/dhgr/make.py memory)
raw: bytes as the game uses them. packed: zlib -9 (a stand-in for Tisple's packer).
lit sprites: picture + mask, every frame whole; trimmed: each row only its bytes, and a
frame that is idle moved plus a patch (the hop, a new face) stored as that.
materials: a frame unlit at 3-5 bits a pixel, one copy for every zone (light.py).
