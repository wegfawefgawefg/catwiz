# Dog Witch ][ (private)

A private Apple II hi-res take on Dog Witch, written in Tisple ][
(github.com/wegfawefgawefg/tisple). Fan project for the owner's own use: never
public. Game data read from the owner's Steam copy is reference only and stays
out of git (data/extracted/); all art is redrawn for hi-res.

- `mockup/`: exact hi-res mockups of screens, to settle layout and draw cost
  before game code.
- `tools/`: data extraction and the mockup composer.
